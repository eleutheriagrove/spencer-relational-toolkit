# Spencer Relational Toolkit (Pathfinder POC)

Prototype operational toolkit for relational cognition bounds inspired by Herbert Spencer’s *First Principles*.

## Core Bounds
- **Terminal triad axiom**: Force (action-causing residual), Space (co-existence structure), Time (sequential index) remain distinct. Force is not derived from bare coordinates or Space alone.
- **Persistence bound**: The residual that makes conservation possible is prior to the particular metrics in which charges are written.
- **Thread-end bound**: Neither absolute origin nor absolute terminus of a process is an element of the process itself.

## Science-to-Conscious-Entity Bound
A scientific model can supply maps of symmetries, gradients, and conserved quantities inside processes. It cannot supply an object that stands for the absolute origin or terminus of the entity’s own modeling activity. The observer index must remain external and the continuation open.
